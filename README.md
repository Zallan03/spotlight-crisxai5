## How it works

`main.ts` (Node 22, standard library only) copies `POST.json` from the repository root to `/output/POST.json` and validates it parses as a JSON object with a string `url`.

Run locally:

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
